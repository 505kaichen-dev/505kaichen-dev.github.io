# Fitment Lab — 輪胎輪圈改裝計算器

入口：`index.html`。純靜態 HTML / CSS / JavaScript，無外部套件、無建置步驟，可直接開啟或由既有 Web Server 提供。

## 功能
- 原廠與目標五項尺寸輸入：胎寬、扁平比、輪圈直徑、輪圈寬度、ET。
- 四格 SVG 動態圖：原廠 / 目標的側面與正視剖面示意，採共同尺度。
- 固定安裝面、輪圈中心線、ET 標示、可切換原廠輪廓疊加。
- 外徑、胎壁、輪圈內外緣位移與理論速度差計算。
- 無效 / 空白輸入保留最後有效規格並顯示欄位錯誤。
- 手機雙欄圖面、單欄輸入，複製原廠與重設範例。

## 模型限制
標稱尺寸幾何估算。輪圈寬為胎唇座間距，不含輪緣厚度。胎壁外形僅示意，不能推算輪胎廠核准配圈範圍、實際裝胎後寬度或確定干涉。圖面左內右外，正 ET：中心線在安裝面內側。

ET 定義：https://www.tirerack.com/upgrade-garage/what-is-wheel-offset

## 進階輪胎資料
- 每組增加獨立啟用開關：廠商實測斷面寬 + 量測 J 值成對；胎面寬與輪圈總寬選填。
- 估算斷面寬 = 實測斷面寬 + (目前 J − 量測 J) × 10.16 mm；外徑、胎壁高度和 GPS 速度仍使用標稱尺寸，避免將斷面修正誤當外徑變化。
- 正視圖最寬點對應估算斷面寬；提供胎面寬後繪出胎肩寬度，未提供時保留示意。
- 顯示輪胎內外側相對原廠位移；提供輪圈總寬後顯示胎壁每側超出 / 收進框邊距離（假設輪緣對稱）。J 值內外緣比較仍以胎唇座為基準。
- 非法值、未成對、胎面寬超過斷面寬、輪圈總寬小於胎唇座寬時提示，整組進階資料回退標稱模式。清空 / 重設 / 複製原廠包含進階資料。
- 驗證：241 mm @8.5J → 8J 得 235.9 mm；胎面220 mm、輪圈總寬228 mm時每側超出4.0 mm。缺量測 J、胎面250 mm均正確提示並回退，停用進階回到235 mm，瀏覽器無主控台錯誤。

## 葉子板位置參考
- 新增獨立开關，輸入原廠輪胎胎壁最外側相對葉子板的內縮 / 齊平 / 突出距離（0～200 mm）。
- 葉子板位置 = 原廠輪胎外側座標 + 內縮距離（突出為負）；目標剩餘內縮 = 葉子板位置 − 目標輪胎外側座標，負值顯示突出。
- 正視圖顯示共用葉子板線，套用進階斷面修正。輸入修改原廠規格時重新建立基準並提示核對實測距離；不推算動態磨胎。
- 驗證：原廠內縮20 mm、預設目標外移15 mm → 目標內縮5 mm；目標ET25 → 目標突出5 mm；空白距離提示並移除標示。無主控台錯誤。

- 葉子板外緣改為輪胎頂部上方短線，垂直延伸僅為淡色位置投影線；高度為示意，水平位置計算不變。

- 車身／葉子板外緣改為輪胎上方垂直短線，下方淡色投影線維持水平位置比較用途。

- 葉子板結果改為完整描述：輪胎仍在葉子板內側 / 超出葉子板 / 外側齊平；另以『比原廠向外／內移』區分位移量與最終位置。

- 葉子板距離線移至上方胎壁最寬點，與外側斷面寬座標相接，新增端點與『胎壁距離』數字，避免誤認為輪圈距離。
