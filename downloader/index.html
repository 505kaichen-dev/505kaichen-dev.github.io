02 / IMAGES

圖片不只是一串網址。

解析度、比例、格式和大小直接列出。用 Shift 選一整段，或按住滑鼠拖曳勾選；不想看的欄位，就把它收起來。

A FEW THINGS TO KNOW

用之前，
你可能想知道。

支援範圍、登入與可攜性，
一次說清楚。

哪些網站能用？＋

已知品牌辨識包括 YouTube、Bilibili、Pornhub、XVideos、xHamster、RedTube 與 YouPorn。其他影片頁面交由 yt-dlp 嘗試解析；圖片模式分析目前頁面的圖片來源。網站改版、地區限制與反自動化機制都可能影響結果，不保證所有頁面皆可使用。

會讀取我原本瀏覽器的登入資料嗎？＋

不會。Downloader 使用自己的 WebView2 登入環境，你在官方網站完成登入。登入紀錄留在目前電腦，以 Windows 使用者層級加密保存；不會在啟動時逐站連線掃描。

能放在 NAS 或 USB 上嗎？＋

主程式、解析工具、設定與紀錄可以放在 NAS、USB 或本機資料夾。登入資料保存在各台電腦，換電腦需重新登入；登入視窗使用 Microsoft WebView2，電腦需有可用的 WebView2 Runtime。

大會員或 Premium 能下載最高畫質嗎？＋

登入後可嘗試取得該帳號可存取的格式。最終畫質仍取決於網站、帳號權限與解析引擎支援；Downloader 不提供 DRM 解密或會員權限繞過。

圖片解析度為什麼有些顯示未知？＋

程式會讀取有限的圖片檔頭辨識尺寸。網站拒絕請求、格式未涵蓋或內容動態載入時，可能無法取得尺寸；未知不代表一定不能下載。

可以拿來做二創或迷因嗎？＋

這也是開發這個工具的使用情境。軟體供個人、非商業使用；取得檔案不代表取得素材授權，使用與分享前仍需確認素材權利及來源平台規範。
