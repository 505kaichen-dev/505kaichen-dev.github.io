# IBM 調價趨勢 Release Notes

版本號採用 `verYYYYMMDD`，與登入畫面顯示一致。同一天內的多次發布合併記錄在同一版本，最新版本置頂；功能、資料、介面或修正都應在發布前補入本文件。

## ver20261001

### 新增

- 登入畫面加入日期版本號，建置時自動依發布日期更新。
- 所選曲線明細的採用漲幅說明增加判定來源，區分「公告基準」、「零件平均」及沒有產品調價時的「產品漲幅」。
- 建立正式 Release Notes，回溯整理既有版本，並納入後續發布檢查流程。

### 修正

- 修正部分節點未顯示採用漲幅 memo 的問題。現在每筆明細都會顯示 Excel「調價明細」N 欄的採用漲幅；有匯率時，同時顯示 F 欄匯率，方便核對 O 欄綜合漲幅。
- 修正比較基準日拉桿的圓點、進度色條與日期刻度未完全對齊的問題。首端、中間與末端節點改用同一組位置計算。

相關提交：`b953f62`、`882452f`

## ver20260930

### 資料更新

- 加入較早的歷史基準與調價節點，圖表可從 2025 年延伸至 2026 年。
- 補入及修正歷史匯率調整，產品漲幅與 TWD 匯率分開保存後以複利合併。
- Excel、網站及建置工具統一採用「公告基準／公告下限」用詞。

### 介面調整

- 收斂首頁重複摘要、密集標籤及過長來源檔名，時間軸優先顯示每次調價重點。
- 增加「如何解讀這張圖」，說明指數 100、公告基準、零件平均、匯率複利及 MTM 適用範圍。
- 公告範圍、來源檔案及曲線明細改為可展開內容。
- 明細表簡化為生效日、曲線／MTM、變動原因、當期變動及累積指數。

### 新增

- 增加「顯示各節點數值」開關。預設只顯示最新指數，開啟後顯示所有日期的指數，匯出 PNG 亦套用相同設定。
- 圖表指數後加入 `[1]`～`[9]`，對應下方調價時間軸節點。

相關提交：`84a007c`、`d2d1309`、`303281f`、`2de454c`

## ver20260929

### 初版功能

- 建立 Storage、Power Server、TAPE Library 三類產品選擇及型號多選。
- 建立累積價格指數階梯圖、浮動比較基準日、節點提示與最後數值虛線延伸。
- 支援高解析度 PNG 匯出，供簡報使用。
- 採用商務淺色介面，並加入可折疊的所選曲線明細。

### 發布與安全

- 建立 GitHub 加密版登入畫面，價格資料只有在輸入密碼後才於瀏覽器記憶體解密。
- 建立內網版、GitHub 加密版及單檔離線版的共用建置流程。
- 確立 Excel 為唯一資料來源，加入欄位檢查、加密資料產生及離線檔案封裝工具。
- 建立維護文件，記錄計算規則、歷史節點新增方式、發布流程及安全界線。

### 用詞與閱讀調整

- 將容易誤導的 `Overall` 改為「公告基準」，節點公告值稱為「公告下限」。
- 所選曲線明細預設收合，降低首頁資訊量。

相關提交：`d654d63`、`9e3464c`、`c9b6547`、`f3173ab`
